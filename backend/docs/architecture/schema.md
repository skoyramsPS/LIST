## Schema conventions

Every table that participates in the sync protocol must carry:

- `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()` — LWW timestamp (plaintext sync metadata)
- `deleted_at TIMESTAMPTZ` — soft-delete tombstone; NULL means the row is live
- `encrypted_payload TEXT NOT NULL` — the E2EE blob; server never decrypts this
- `sync_version BIGINT NOT NULL DEFAULT 0` — monotonic version for conflict detection
- `device_id UUID NOT NULL` — the device that last wrote this row

The server is dumb: it stores and retrieves blobs. All merge logic runs on-device.
